# Java Projects ☕

A collection of Java projects built to practice programming concepts and develop practical applications.

## 📁 Projects

### 1. Rock Paper Scissors

A simple **CLI-based Rock Paper Scissors game** built using Java.

**Features:**

* 🎮 Play Rock, Paper, Scissors from the terminal
* 🤖 Computer-generated moves
* 🏆 Determines the winner of each round
* 🔄 Supports multiple rounds
* 🧹 Clears the terminal between rounds
* ⚠️ Basic exception handling

**Technologies:**

* Java
* Java Collections
* Enums
* Exception Handling

## 🚀 Running the Project

Clone the repository:

```bash
git clone [<repository-url>](https://github.com/sahil-shv/Java-Projects.git)
cd Java-Projects
```

Compile and run:

```bash
javac rockPaperScissor.java
java rockPaperScissor
```
